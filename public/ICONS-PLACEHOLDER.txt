# Favicon & Icon Files - Upload Later

This site is configured to use the following icon files.
Upload them to this folder when ready.

Required Files:
- favicon.ico (48x48)
- favicon-16x16.png (16x16)
- favicon-32x32.png (32x32)
- favicon-48x48.png (48x48)
- apple-touch-icon.png (180x180)
- android-chrome-192x192.png (192x192)
- android-chrome-512x512.png (512x512)
- og-image.png (1200x630) - for Facebook/LinkedIn sharing
- twitter-image.png (1200x675) - for Twitter cards

See FAVICON-GUIDE.md for detailed instructions.

The site will work without these files, but they improve:
- Browser tab icons
- Mobile home screen icons
- Social media sharing previews
- Professional appearance

Generate icons at: https://realfavicongenerator.net/
